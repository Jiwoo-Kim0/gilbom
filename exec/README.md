# 길봄 제출용 실행·포팅 자료

이 디렉터리 이름은 제출 요구사항에 맞춰 정확히 `exec`로 유지한다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `1_포팅_매뉴얼.md` | GitLab clone 이후 운영 기준 빌드·배포·검증·Jetson 배포 절차 |
| `2_외부_서비스_정보.md` | 가입/발급이 필요한 외부 서비스와 설정 주입 위치 |
| `3_DB_dump.sql` | 운영 DB 최신 덤프를 넣을 자리. 현재는 의도적인 placeholder |
| `3_DB_덤프_생성_및_복구.md` | 운영 서버에서 최신 덤프를 생성·검증·복구하는 방법 |
| `4_시연_시나리오.md` | 시연 전 준비와 화면별 클릭 순서·확인 결과 |

## 미확인 값 표기 규칙

- `________________`: 담당자가 실제 운영값을 확인하여 채워야 하는 항목
- `미확인`: 저장소만으로 확정할 수 없는 항목
- 비밀번호, API Key, private key, webhook URL 원문은 이 문서에 적지 않는다.
- `3_DB_dump.sql`은 운영 서버에서 새로 생성하기 전까지 실제 덤프가 아니다.

## 제출 전 최종 확인

1. `1_포팅_매뉴얼.md`의 "제출 전 작성 필요 항목"을 모두 채운다.
2. 운영 서버에서 `3_DB_덤프_생성_및_복구.md` 절차로 `3_DB_dump.sql`을 교체한다.
3. 덤프 파일의 생성 시각·Commit SHA·Flyway 최신 버전을 기록한다.
4. `4_시연_시나리오.md`의 시연 계정·로봇·구역 값을 실제 값으로 채운다.
5. Secret 원문과 실제 개인정보가 Git에 포함되지 않았는지 확인한다.
