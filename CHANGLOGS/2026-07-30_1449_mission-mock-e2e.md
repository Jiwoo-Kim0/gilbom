## 작업 요약

`S15P11D101-379`, `DAY6-B-00-8`의 로컬 완료 조건으로 실제 TLS Mosquitto,
Python Mock Robot, Spring Backend, 임시 PostgreSQL, REST/SSE, React,
Playwright Chromium을 하나의 자동화된 Mission 흐름으로 연결했다.

Mission은 `CREATED → RUNNING → PAUSED → RUNNING → COMPLETED`로 전이했고,
완료 전 진행률 상한 99.99%, PAUSED 중 벽시계 경과시간 증가, 완료 Event의 100%,
상태 이력 5건, 실제 Telemetry 궤적, 현재 위치, Command 3건 완료를 Browser와
DB에서 대조했다.

작업 중 병합된 Robot Image API V31과 시간 기반 Mission V31의 Flyway Version
충돌은 Mission Migration을 V32로 이동해 해소했다. 프론트 `.env`와
`vite.config.ts`는 변경하지 않았다.

## 상세 내용

### Mock Robot

- Command Request 처리 성공 직후 대응 Mission Event를 QoS 1, Retain false로
  발행한다.
- Event는 MQTT v2의 `schema_version: "2.0"`, `mqtt_id`, `boot_id`, 공용
  `seq`, UUID `event_id`, `source_component: "mission"`, `ttl_sec`,
  `mission_id` 규칙을 따른다.
- 중복 `command_id`는 저장된 Result만 다시 보내고 상태 변경과 Event 발행을
  반복하지 않는다.
- 자동 완료는 마지막 비종단 Telemetry 뒤 `MISSION_COMPLETED`와 완료 State를
  발행해 Backend가 100%를 Event에서만 확정하도록 했다.

### Browser·실행기

- Browser는 CSRF와 `Idempotency-Key`를 포함해 실제 Command API를 호출한다.
- React가 SSE 후 재조회한 상태 Badge를 기준으로 RUNNING·PAUSED·COMPLETED를
  관찰한다.
- REST로 PAUSED 경과시간, 완료 진행률, Completion Reason, 이력 출처를 대조한다.
- Map Snapshot의 Polygon/MultiPolygon, 실제 Trajectory, Current Position을
  검증한다.
- 실행기는 빈 임시 DB에 현재 Backend Migration 전체를 적용하고 종료 시 임시
  Container·DB를 제거한 다음 기존 Backend Health를 확인한다.
- Broker Credential과 비밀번호는 현재 Container 환경에서 읽되 출력하지 않는다.

### Migration 충돌

동시 병합 후 다음 두 파일이 V31을 함께 사용해 Backend 전체 테스트의
ApplicationContext 초기화가 실패했다.

```text
V31__create_robot_image_api_key.sql
V31__add_time_based_mission_contract.sql
```

Robot Image API를 V31로 유지하고 Mission을 V32로 이동했다. 파일명 Version
스캔 결과 총 32개 Migration이 모두 고유하며 현재 소스로 빌드한 Backend가 빈
임시 DB에 정상 기동했다.

## 영향 및 주의사항

- `mission-mock-e2e.py`는 실행 중 로컬 8080의 기존 Backend를 잠시 교체하므로
  로컬 또는 격리 CI 전용이며 운영 EC2에서 실행하면 안 된다.
- 실패 경로도 `finally` 정리를 수행하지만 실행 후 기존 Backend Health와 임시
  Container·DB 0건을 다시 확인해야 한다.
- `.env`와 `vite.config.ts`가 없어도 현재 로컬 `/api → 127.0.0.1:8080` 구조로
  실행된다. EC2는 Nginx 상대경로 Proxy 설정을 정본으로 사용한다.
- Naver 운영 Key·Origin 검증과 실제 Jetson Payload 검증은 로컬 Mock 성공과
  구분한다.
- 충전 관련 Mission 흐름은 현재 범위에서 제외했다.
- 작업 전부터 존재한 `.gitignore`, 다른 팀원의 Robot Image API 및 다수
  Untracked 문서·Build Directory는 이번 작업에서 정리하거나 되돌리지 않았다.
