## 작성 규칙

- 파일명에 주제와 문서 종류를 담는다. 폴더가 담당자를 나타내므로 담당자 접두어는 넣지 않는다.
- **형제 문서를 가리키는 상대 링크는 `../../`로 쓴다.** 이 폴더는 `web/docs/`에서 두 단계
  아래다. `](defect-schema.md)`나 `](../defect-schema.md)`로 쓰면 깨진다.
  작성 후 대상 파일이 실제로 있는지 확인한다.
- 나중에 다시 읽을 때 가장 쓸모 있던 절은 다음 셋이었다. 새 문서도 이 구성을 유지한다.
  - **설계 판단과 그 이유** — 코드만 봐서는 알 수 없는 배경
  - **작업 중 겪은 함정** — 같은 곳에서 다시 시간 낭비하지 않도록
  - **미완 항목을 소유자별로** — 내 몫과 다른 팀원 몫을 구분
