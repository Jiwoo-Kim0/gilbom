기간: 2026-08-06
범위: `/robots` 화면 CSS(`app/robot/css/robot.css`)와 상태 색 변수(`index.css`).

관련 문서: [결함-필터-UI-드롭다운_작업내용.md](결함-필터-UI-드롭다운_작업내용.md) §19.4

## 1. 무엇이 문제였나

**검색 줄이 너무 두꺼웠다.** 한 줄짜리인데 위아래 여백이 32px씩 붙어 높이가 108px이었다.

**지도 범례가 필터 칩처럼 보였다.** 테두리 + 둥근 모서리 알약 모양이라 눌러서 거를 수
있는 것처럼 읽힌다. 실제로는 마커 색 설명일 뿐이다.

**온라인과 오프라인 색이 거의 같았다.** 온라인이 `--brand-strong`(#7a5c0c, 어두운 금색),
오프라인이 `--text-muted`(#6f6a5e, 회갈색)이라 둘 다 어두운 갈색 계열이었다. 상태를
한눈에 갈라 보려고 색을 쓰는데 그 목적이 서지 않았다. 충전 중도 `--nb-gold`(#b8863b)라
온라인과 붙어 보였다.

## 3. 상태 색은 변수로 묶었다

같은 색이 **범례 점·지도 마커 상태 점·목록 상태 배지** 세 곳에 흩어져 있었다.
`index.css`에 변수로 올려 한 곳에서 바꾸게 했다(결함 유형 색과 같은 방식이다).

```css
--robot-online: #55b83a;          /* 점·마커 */
--robot-online-strong: #2f7d20;   /* 배지 글자 */
--robot-online-soft: #e8f6e2;     /* 배지 배경 */
```

**작은 점은 채도가, 글자는 명암이 필요하다.** 연두를 배지 글자에 그대로 쓰면 흰 배경에서
읽기 어려워, 배지에는 진한 값(`-strong`)과 연한 배경(`-soft`)을 따로 뒀다.

**건드리지 않은 것**: 실시간 스트림 연결 표시(`.robot-stream-status-*`), 배터리 게이지,
시스템 로그 아이콘. 색이 같아 보여도 로봇 상태가 아니라 다른 축이다.

## 4. 함정 — `@import`한 CSS는 특이도가 같으면 진다

`.robot-filter-bar`에는 이미 `padding: 18px 20px`이 있었다. **그런데 화면에는 32px이
적용되고 있었다.**

`App.css`가 첫 줄에서 `@import './app/robot/css/robot.css'`로 들여온다. `@import`한 내용은
그 파일의 앞쪽에 놓이므로, 뒤에 나오는 `App.css`의

```css
.content-card { padding: clamp(22px, 3vw, 32px); }
```

이 같은 특이도(클래스 1개)로 **나중에 선언돼 이긴다.** 1280px 화면에서 `3vw = 38.4px`가
상한 32px로 잘려 32px이 된 것이다.

그래서 클래스를 둘 붙여 특이도를 올렸다.

```css
.content-card.robot-filter-bar { padding: 12px 20px; }
```

**`robot.css`에서 `.content-card`의 값을 덮으려면 항상 이렇게 해야 한다.** 같은 방식으로
쓰인 곳이 더 있는지는 확인하지 않았다(§6).

## 5. 확인한 것

브라우저에서 계산된 값을 직접 읽었다(임시 스펙, 커밋하지 않음).

```
이전: searchBar { paddingTop: 32px, height: 108 }  legend { border: 1px, radius: 999px, height: 38 }
지금: searchBar { paddingTop: 12px, height:  68 }  legend { border: 0px, radius: 0px,   height: 19 }
```

상태 색도 계산된 값으로 확인했다.

```
점    online rgb(85,184,58)  warning rgb(229,50,42)  charging rgb(242,194,0)  offline rgb(111,106,94)
배지  online #2f7d20 on #e8f6e2   warning #ad211a on #fde8e6   charging #8a6a00 on #fdf3cf
```

스크린샷으로도 검색 줄이 한 줄에 맞게 얇아지고, 범례가 `● 온라인(—) ● 경고(—) …`로
읽히며, 배지 넷이 서로 다른 색으로 갈리는 것을 봤다.

**CSS만 그려 확인할 때 주의**: `App.css`를 `addStyleTag`로 넣으면 그 안의
`@import './app/robot/css/robot.css'`는 해석되지 않아 로봇 규칙이 통째로 빠진다(배지가
스타일 없이 나왔다). 실제 cascade와 같은 순서(`index.css` → `robot.css` → `App.css`)로
직접 이어붙여야 한다.
