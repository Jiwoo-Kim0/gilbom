## 용도

| 위치 | 용도 | 새 문서 추가 여부 |
| --- | --- | --- |
| `팀원B-remaining-7days.md` | 완료·미완료·요구사항·남은 실행 순서의 현재 상태판 | 상태가 바뀔 때 갱신 |
| `작업내용/` | 같은 종단 흐름으로 묶은 현행 구현·검증·함정·미완 인계 | 하위 작업 완료 시 추가 |
| `V2/` | 현재 Robot Schema·등록·Credential Provisioning 상세 참고 | 계약 변경 시에만 갱신 |
| `V1/` | 초기 Schema 검토 보관본 | 신규 구현에서 사용 금지 |
| `작업 내용/` | 2026-07-27 초기 원시 작업 기록 | 보관만 하고 새 파일 추가 금지 |

`작업 내용/`과 `작업내용/`은 이름이 비슷하지만 역할이 다르다. 기존 기록을
임의로 삭제하거나 덮어쓰지 않고, 앞으로의 완료 기록은 공백 없는
`작업내용/`만 사용한다.
